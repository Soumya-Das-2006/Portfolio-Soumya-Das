## 💻 Run Locally

To run the portfolio on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/Soumya-Das-2006/Portfolio-Soumya-Das.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio-Soumya-Das
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code if your project requires a local development server.
